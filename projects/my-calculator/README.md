# My Calculator v0.1

A desktop calculator built with **Python** and **Flet**.

## Features
- Addition, subtraction, multiplication, and division
- Clear and backspace controls
- Factorial
- Square root
- Power operator
- Dark interface with purple and teal buttons

## Run locally

```bash
python -m pip install -r requirements.txt
python MyCalculater.py
```

## Project structure

- MyCalculater.py — application source
- requirements.txt — Python dependency

This is an early learning project and may be improved in future versions.
