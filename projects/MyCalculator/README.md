# My Calculator v0.1

A small desktop calculator built with **Python** and **Flet**.

## Features

- Basic arithmetic: addition, subtraction, multiplication, and division
- Clear and backspace buttons
- Factorial
- Square root
- Power operator
- Dark interface with a custom button color palette

## Screenshot

The project screenshot is available in the original development conversation. It has not been added as a repository image yet.

## Requirements

- Python
- Flet

## Run locally

1. Install Flet:

   ```bash
   pip install flet
   ```

2. Run the application:

   ```bash
   python MyCalculater.py
   ```
